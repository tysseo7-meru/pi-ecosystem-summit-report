要約

Pi初のエコシステムサミット。AIの助けでアプリを作る開発者コンソールとMCP、最大2,000万Piの成長支援、定期課金とx402決済の実証、Pi DataLab、SoloHostのAI包装スキル、CiDi Games、Resonantに加え、最終日は賞金20万USDTのハッカソン「Pi Next」が始まった。

  • 中心は、アプリ作りをAIに手伝わせる仕組みであった。新しい開発者ウェブコンソール（ブラウザで使う開発者向けの管理画面）とMCPサーバー（AIがPiの開発者向け道具を使えるようにするための接続の仕組み）により、AIコーディングエージェント（プログラムを書くAI）がアプリの作成・登録、設定、Pi認証・Pi決済の組み込み、アプリ一覧への掲載申請までを代行する。創業者ニコラス・コッカリスによるデモでは、マルチプレイ（複数人で対戦できる形）対応の三目並べアプリを一から構築し、通知と決済（支払いと返金）までを通した。
  • Pi財団が資金を出す App Growth Initiative（アプリの成長を支援する取り組み）が発表された。予算は最大2,000万Piで、対象アプリは実績に応じてその一部を使い、KYC（本人確認）済みユーザーの獲得と参加を促す。参加条件と報酬額の詳細は後日発表される。
  • Piアプリ一覧（ディレクトリ）が刷新された。既存のステーキング（Piを預けてアプリを応援すること）による順位付けを残しつつ、「ブックマーク」「ステーキング済み」「上昇中」「発見」「何度も戻ってくる」といった新しい区分が追加された。
  • Pi Launchpad（新しいトークンの発行を支援する仕組み）、分散型取引所（DEX、運営会社を介さず利用者同士で売買する取引所）、自動マーケットメーカー（AMM、価格を自動で計算して売買を成立させる仕組み）は2027年第1四半期にメインネット（本番のネットワーク）へ移行する。Launchpadを通じた初のメインネットトークン発行も含まれる。
  • ブロックチェーン上に記録される定期課金スマートコントラクト（条件に応じて自動で実行されるプログラム）と x402 決済がテストネット（試験用のネットワーク）で実証された。定期課金は2026年4月にテストネットへ初導入されたものである。x402 では OpenMind の RoboPay がロボットへの支払い（0.01テストPi）を実演した。
  • 本人確認済みのパイオニアをAIの作業につなぐ新しいプラットフォーム「Pi DataLab」が紹介された。企業やAI開発者は、データのラベル付け（データに正解の目印を付けること）や評価など人間の判断を要する作業を依頼でき、参加したパイオニアは Pi またはトークンで報酬を受け取る。初版は完成しテスト環境で動作しており、公開されるパイロット版（試験公開版）ではメインネットのウォレットを通じた決済がつながる見込みである。
  • SoloHost 向けの新しいAIスキル（AIに特定の作業をさせるための手順書のようなもの）が実演された。既存アプリの公開Dockerイメージ（アプリとその動作環境をひとまとめにした配布用のデータ）を示すと、AIエージェントが SoloHost への掲載に必要な2つの設定ファイルを生成し、検証まで行う。デモでは AIエージェントアプリ OpenClaw を例に、Pi Desktop 上での公開と動作までを示した。
  • CiDi Games の技術デモでは、Pi認証、Pi決済、Pi広告SDK（広告を組み込むための開発キット）、ローカルストレージ（端末側の保存領域）の統合手順が示された。デモはローカル（手元の環境）で動作する見本を用いたものであり、バックエンド（裏側のサーバー処理）によるアクセストークン（ログイン済みであることを示す符号）の検証はまだ実装されていないことが明示された。

サミットについて

Piエコシステムサミットは Pi Network 初の開発者向けサミットであり、2026年11月17日から19日までオンラインで開催された。Day 1（11月17日）のテーマは「開発者プラットフォーム、エコシステム施策、アプリ紹介」である。Day 1 の本編動画は Pi Network 公式YouTubeチャンネルでプレミア公開（公開時刻を決めて初めて公開する形式）され、長さは1時間45分5秒である。Day 2（11月18日）は「AIとエコシステム」、Day 3（11月19日）は賞金20万USDTの新ハッカソン（開発者がアプリ作りを競う催し）「Pi Next」のキックオフ（開始の行事）で、動画番組はなく、告知は Pi アプリのトップ画面に表示された @PiCoreTeam の投稿「Pi Ecosystem Summit Day 3」の形で行われた。この投稿には2つのボタンがあり、左の「Join Hackathon」は Pi Next の公式ページへ、右の「Ecosystem Summit」は新しい公式ページ（minepi.com/ecosystem-summit/）へつながっていた。この新しい公式ページは、サミット全体の案内ページで、3日分の内容（Day 1＝開発者プラットフォーム、Day 2＝AIとエコシステム、Day 3＝Pi Next ハッカソンの開始）を日ごとにまとめて紹介している。

開会の挨拶で創業者のチェンディアオ・ファンは、エコシステム（Piを中心とするアプリや利用者の広がり）の規模として、参加中のパイオニア6,000万人超、メインネットアプリ300超、ノード（ネットワークを支えるコンピューター）42万超、KYC（本人確認）完了ユーザー1,810万人超を紹介した。これらの数値は公式発表によるものである。

結果1：AI支援の開発者体験（開発者ウェブコンソールとMCP）

Day 1 の中心は、アプリ作りをAIエージェント（指示を受けて作業を代行するAI）に手伝わせる仕組みの刷新であった。新しいブラウザ型の開発者ウェブコンソール（developers.minepi.com、ブラウザで使う開発者向けの管理画面）と、Piの開発者ツールに接続する MCP（Model Context Protocol、AIが外部の道具やサービスにつながるための共通の取り決め）サーバーが導入された。対応するAIコーディングエージェント（プログラムを書くAI）に自然言語（ふだんの言葉）で指示すると、アプリの作成と登録、設定とURLの構成、Pi認証やPi決済といった Pi API（Piの機能を外から呼び出すための窓口）の組み込み、アプリ一覧への掲載申請までをエージェントが実行する。秘密情報（APIキーやウォレットの秘密鍵）はエージェントに見せない設計であり、必要な場面では人の承認が求められる。従来の手動の手順でも同じコンソールを使える。

創業者ニコラス・コッカリスによるデモでは、AIエージェントが三目並べゲーム「Pocket Grid」を一から構築した。デモで示された流れは次のとおりである。

  • エージェントがゲームを構築し、公開HTTPS URL（インターネットからアクセスできる住所）へ展開（公開）した。開発当初は Pi との連携がない通常のアプリであった。
  • エージェントが Pi の MCP サーバーへ接続し、アプリを登録した。Pi Sandbox（Piブラウザを模した開発用環境）でアプリを読み込み、動作を検証した。
  • マルチプレイ機能を追加した。部屋を作成し、PiNet リンク（pinet.com で終わるURL）で友人を招待する。PiNet リンクを開くと Piブラウザでアプリが開く仕組みである。
  • 通知機能を追加した。手番が来た相手に通知を送る。サーバー間の通信には APIキー を使い、キーは開発者がコンソールで生成して安全な場所に保管する。
  • Pi決済を追加した。部屋の作成時に1 Piを支払い、誰も参加しなければ返金する流れを実演した。ユーザーからアプリへの支払いと、アプリからユーザーへの返金の両方向を示した。テストネットでの実演であり、アプリ側ウォレットの秘密鍵はエージェントに渡さず、開発者が保管した。
  • 最後にアプリ一覧への掲載申請の手順を示した。申請内容の多くはエージェントが事前に用意していた。

デモで示された所要時間は、マルチプレイまでの構築が約10分であった。ブログ記事も「従来は数日かかっていた手順が数分で済む」と説明している。

結果2：Pi DataLab（人間の判断をAIにつなぐ新プラットフォーム）

Pi DataLab は、企業・AI開発者・団体が、本人確認済みの世界中のパイオニアに、人間の判断を要する作業を依頼できる新しいプラットフォーム（仕事の仲介の場）である。「ヒューマン・イン・ザ・ループ」とは、AIの処理の流れの中に人間の判断を組み込む考え方をいう。AIの学習・評価・改善に必要なデータ生成、ラベル付け（データに正解の目印を付けること）、評価、順位付け、レビュー、フィジカルAI（現実の身体や機械を扱うAI）向けデータなど、人間の理解が要る作業が対象である。依頼側はプロジェクトを作成して資金を用意し、参加するパイオニアは自発的に作業を選び、判断や作業を提供して、完了した貢献に対して Pi またはトークンを受け取る。

デモでは、顧客対応チケット（問い合わせの記録）の感情分類（肯定的・中立的・否定的）を例に、プロジェクト作成から公開までの流れを示した。プロジェクト名「ticket sentiment」、作業ごとに5件の回答を求める設定、KYC済みであること・言語・地域などの参加条件を設定し、Piの審査を経て公開される。公開後は、作業の開始・完了までの平均時間や承認率などの指標を確認できる。作業者側にはタスクのマーケットプレイス（作業を選べる一覧）が表示され、報酬と所要時間の目安を確認して作業を選ぶ。報酬は月払いである（デモ中の説明による）。

品質を保つ仕組みとして、作業者の評判が記録される。努力の有無、作業の開始・完了にかかる時間、提出回数、正答率などが信号（評価の材料）となり、質の維持と将来の作業の割り当てに使われる。

初版は完成し、テスト環境で動作している。デモはテスト環境で行われ、決済は有効化されていない。公開されるパイロット版（試験公開版）では、メインネットのウォレットを通じた決済がつながる見込みである。公開時期は明示されていない。

背景として、PiのKYC検証の仕組みは、100万人超の本人確認済みの検証者が5億2,600万件超の検証作業を完了した実績がある（ブログ記事による）。ブログ記事は、報酬が法定通貨（円やドルなど国が発行する通貨）ではなく Pi を含むトークンで支払われる点を、従来のWeb2型プラットフォーム（従来型のウェブサービス）との違いとして説明している。

結果3：SoloHost のAIスキル（既存アプリの包装を自動化）

SoloHost は、開発者が自己ホスト型アプリ（自分のサーバーで動かすアプリ）を Pi Desktop へ持ち込み、42万人超のノード運営者と Pi Desktop 利用者に配布できる仕組みである。Dockerイメージ（アプリとその動作環境をひとまとめにした配布用のデータ）として包装（配布できる形にまとめること）ができる作業負荷であれば、SoloHost 上で動作する可能性がある。新しいAIスキル（AIに特定の作業をさせるための手順書のようなもの）は、この包装作業をAIエージェントに任せるためのものであり、公開リポジトリ（プログラムの保管場所、github.com/pi-node/solohost）で提供されている。対応するAIエージェント（Claude Code、Cursor、Codexなど）に既存アプリの公開Dockerイメージを示すと、エージェントがアプリの機能を調べ、必要な設定を尋ね、包装に必要な2つのファイル（docker-compose.yml と config_options.yml）を生成し、SoloHost の検証プログラムで確認する。イメージ自体の構築はスキルでは行わない。

デモでは、AIエージェントアプリ OpenClaw を例に、スキルが3つのモデル提供者（AIモデルを提供する会社、Anthropic、OpenAI、OpenRouter）と Telegram 連携、DuckDuckGo によるウェブ検索などの機能を調べ、利用者が選んだ機能だけを反映した2つのファイルを生成し、検証プログラムの指摘を自ら修正したうえで、ローカル（手元の環境）での動作確認まで行う流れを示した。生成した2つのファイルを SoloHost へ貼り付けて公開すると、Pi Desktop 上でアプリが動作し、天気の質問に回答した。

結果4：オンチェーン定期課金と x402 決済（テストネットでの実証）

オンチェーン定期課金スマートコントラクト

Piのオンチェーン定期課金スマートコントラクトは、アプリに継続課金（月額料金のような定期的な支払い）の機能を組み込むための仕組みである。「オンチェーン」はブロックチェーン上に記録する形をいい、「スマートコントラクト」は条件に応じて自動で実行されるプログラムをいう。2026年4月にテストネット（試験用のネットワーク）へ初導入された。利用者は、定額の利用枠と課金期間（例：月額課金で6か月分）を承認するだけで、毎回の更新に署名する必要はない。承認した資金は課金が実行されるまで利用者自身のウォレットに残り、前払いで拘束されない（先に預ける必要がない）。利用者は承認枠の延長や解約ができる。契約のデータは2つの記録（サービス内容と利用者ごとの契約状態）で管理され、チェーン上に約180日間保持される。

Day 1 のデモでは、月額2 Piのサービスを作成し（サービスID 332）、利用者が契約してウォレット側で契約状態を確認する流れを示した。デモ中の例では、次回課金は12月10日から1月10日の期間に加盟店（サービス提供者）が処理できることになっていた。定期課金は現時点ではテストネット限定である。ウォレットと開発者プラットフォーム側の関連機能も整備され、利用者と開発者の双方が使える形になったとブログ記事は説明している。

x402 決済のテストネット統合

x402 は、HTTP の 402（Payment Required、支払いが必要という応答）を使う公開の決済手順である。サーバーが価格・資産・支払先を示し、利用者側が支払い承認に署名して再送すると、仲介者（ファシリテーター）が承認を確認してチェーンへ提出する。資金は支払者から受取先へ直接1回のオンチェーン（ブロックチェーン上）の取引で移動し、仲介者が資金を預かることはない。Coinbase が策定し、x402 Foundation が管理する公開規格である。

Pi は x402 決済を Piテストネットで使えるようにした。Day 1 では OpenMind が Fabric Foundation と共同で開発した RoboPay の実演があった。ロボットへの ping（到達確認の信号）送信の前に 0.01 テストPi を支払い、支払い完了後にコマンドが届く流れを示した。ネットワーク手数料はスポンサー（第三者）負担であり、支払者の残高変動はちょうどマイナス0.01テストPiであった。PiのネットワークID（pinet）は Chain Agnostic の登録簿（登録リスト）に統合済みであり、Piの x402 支払い仕様は公式 x402 リポジトリで審査中である。仕様はテストネットとメインネットの双方を対象とするが、メインネットでの利用開始時期は今後共有される。仕様を実装する Go SDK（開発キット）も用意されている。

結果5：エコシステム施策（成長支援、アプリ一覧、Launchpad）

App Growth Initiative（最大2,000万Pi）

Pi財団が資金を出す新しい取り組み「App Growth Initiative」が発表された。予算は最大2,000万Piである。対象となる開発者は、アプリの質・実用性・利用実績に応じて予算の一部を使える。開発者は自ら報酬を用意せずに、KYC済みユーザーを獲得し、参加を促す仕組みを利用できる。例として、KYC済みのパイオニアが別のKYC済みパイオニアを対象アプリへ招待した場合、紹介者と新規利用者の双方が財団の予算から Pi を受け取れる場合があることが示された。参加条件と報酬額の詳細は後日発表される。この最大2,000万Piの枠組みは、Day 3 に始まった Pi Next の説明でも同じように使われている。Pi Next では、対象アプリを使う・紹介したパイオニアに Pi 報酬が出る仕組みとして説明され、賞金20万USDTとは別の枠であることが明記されている。

Piアプリ一覧の刷新

Piアプリ一覧（ディレクトリ）が大幅に刷新された。従来の「エコシステム・ディレクトリ・ステーキング」（Piを預けてアプリを応援し順位に反映する仕組み）は中心的な仕組みとして残る。そのうえで、関心・成長・利用実績に基づく新しい区分が追加された。

区分内容
ブックマークしたアプリお気に入りのアプリへ戻りやすくする
Piをステーキングしたアプリ従来のコミュニティによるステーキング順位を維持する
上昇中のアプリ勢いのある新しいアプリを紹介する
発見まだ試していないアプリを紹介する
何度も戻ってくる繰り返し利用されているアプリを紹介する

開発者への動機付けは、露出・資金支援・評価の3つで構成される。資金支援の一例として、Pi App Studio の料金は、実際の利用と実用性を示す開発者には割引価格が適用される。評価としては、アプリ一覧にアプリや開発者の状態が表示されるほか、優れたアプリは Pi Network Ventures からの投資や Launchpad の候補になる機会がある。

Pi Launchpad、DEX、AMM の2027年第1四半期メインネット化

Pi Launchpad、分散型取引所（DEX）、自動マーケットメーカー（AMM）は2027年第1四半期にメインネットへ移行する。テストネットで複数回の改良を重ねたものであり、Launchpadを通じた初のメインネットトークン発行も含まれる。エコシステム内の特定の用途向けトークンの発行基盤となる。ハッカソン「Pi Next」の参加者にも、トークン発行に向けた準備期間が与えられる。

その他の開発者向け機能

  • PiNetリンクの改善：PiNetリンクを受け取った人が Piブラウザ未導入の場合、アプリストア等から Piブラウザを導入するよう案内され、導入後に元のアプリやページへ直接案内される。招待された人が迷わず遊べるようになり、離脱が減る。
  • 通知センター：アプリから利用者へ Piブラウザ内で通知を送れる仕組みである。携帯電話へのプッシュ通知（端末に直接届く通知）ではなく、Piブラウザ内に通知がまとめて表示される。導入初期は承認なしで最大20人まで通知でき、それ以上は承認が必要である。ネイティブ（端末本来）のプッシュ通知は次の段階であり、迷惑通知を防ぐため限定的な条件が付く。

ファンは今後の戦略として、外部の需要と Pi の共有資源（配布・注目・利用者獲得、利用者の同意を得た上での人の関与による作業やデータ、分散コンピューティング（多数のコンピューターで処理を分け合うこと）、本人確認）を結びつける方針を説明した。ゲームは Pi と相性が良い分野であり、決済・交流・金融参加への入り口になると述べた。ステーブルコイン（価格が安定するよう設計された通貨）の統合や追加の Web3 機能（ブロックチェーンを使う新しいウェブの機能）も、Pi通貨の中心的な役割を損なわない範囲で検討されている。

対話に続き、CiDi Games のゲームプラットフォームが Pi の開発者ツールとどのように統合（組み込み）されるかを、技術デモで示した。対象は Pi認証（サインイン）、Pi決済、Pi広告SDK（開発キット）、ローカルストレージ（端末側の保存領域）である。デモは、実際の本番環境ではなく、ローカル（手元の環境）で動作する見本（サンプル）を用いて、公式SDKの手順をなぞる形で行われた。見本であることは動画の中で繰り返し明示されている。

認証では、ユーザー名と決済の範囲（どこまでの権限を渡すか）を要求し、Piの認証結果（アクセストークンとユーザー情報）を受けて、アプリ側のアカウントと結びつける流れを示した。Piのユーザー識別子はアプリごとに異なるものであり、すべてのアプリで共通の識別子ではないこと、権限を取り消すと変わり得ることが説明された。重要な点として、CiDi Games の現在のバックエンドは、アクセストークンを Pi に問い合わせて検証する手順をまだ実装しておらず、公式の推奨手順（トークンをバックエンドへ送り、Pi へユーザー情報を問い合わせて照合する）とは区別して示された。本番環境で検証が行われているという主張ではない。

決済では、プラットフォーム通貨 CDcoin へのチャージ（入金）を例に、100コインのチャージ（残高101から201へ）を示した。決済の承認・完了・重複防止の各段階を区別し、完了が確認されて初めてコインを付与すること、ブラウザを閉じて決済が中断した場合には未完了の決済を照会して回収する仕組みが説明された。表示された Pi の金額は見本の目安であり、実際の為替相場ではない。

広告では、リワード広告（見ると報酬がもらえる広告）を例に、見逃した毎日のチェックインを広告視聴で補う流れを示した。広告の視聴だけでは報酬は付与されず、バックエンドが Pi へ広告の状態を問い合わせ、仲介者の承認状態（mediator acknowledgement status）が「granted」である場合にのみ報酬が付与される。保留中（pending）や取り消し・失敗では付与されない。広告識別子は一度だけ有効であり、重複請求は防がれる。

ローカルストレージでは、言語設定（英語から日本語への切り替え）を例に、設定がブラウザに保存され、再起動後に復元されることを示した。端末ごとの保存であり、端末間の同期や恒久的な保存を保証するものではない。また、CiDi Games のローカルストレージ利用の承認（ホワイトリスト）状態は未確認であり、動画の中でも確認が必要であることが明言された。

共有のゲームSDKと共通の検証サービスにより、複数のゲームが同じ統合の仕組みを使い回す設計も説明された。例として Meme War と Ian Reap が挙げられた。ただし、両タイトル名の表記は字幕のみが根拠であり、公式資料での裏付けはできていない。

結果8：開発者対話（Resonant）― AIとデータの経済における人間の参加

創業者チェンディアオ・ファンと、AIプロジェクト Resonant のジェイ氏による対話があった。Resonant は、AIの判断を人間の判断と照らし合わせて確かめる仕組みである。人間が倫理的なジレンマ（どうすべきか迷う難しい選択、例：家庭用ロボットが火災時に誰を助けるか）に対して下す判断と、その判断のデータを集め、AIエージェントが人間の判断と一致しているかを測る。現在までに約170万件の判断が集まっており、1,500万件に達すればデータがさらに価値を持つと説明された（発言のみが根拠）。

対話では、データがAI経済における重要な生産資源であること、Pi DataLab がその需要とパイオニアをつなぐ役割を果たすこと、AIエージェントが Pi Desktop 上で動作する SoloHost や Piアプリとして配布できること、Piの本人確認済みユーザー基盤が、AI企業にとって人間の証明とオンボーディング（新規利用者の取り込み）の障壁を下げる価値があることが語られた。Resonant が Pi を選んだ理由として、世界中のユーザーへの露出と、ワンクリックでの本人確認済みログインによる利用者獲得コストの低さが挙げられた。

また、開発者への助言として、アプリを英語のみで書くと利用者の約40%にしか届かず、ネイティブ翻訳（その言語を母語とする人による翻訳）により利用者の取り込みが2〜3倍になるという経験が紹介された（発言のみが根拠）。Piの利用者は9言語を使っていると説明された。

Resonant の今後の方向性として、質問を動画形式で提示するなど、楽しさを伴う形で判断データを集めることが語られた。利用者は自分の判断プロフィール（自分のデータ）を持ち、エージェントと結びつけたり、将来的にはデータの収益化の仕組みにつなげたりすることが想定されている。現在の Resonant は非営利の研究用の検証の仕組みであり、データは詳細を含まず公開されている。

ファンは、テストネットとメインネットの区別をアプリ一覧の掲載手続きから切り離す方針を説明した。アプリの掲載は一覧の手続きとして簡素化し、テストネット／メインネットの区別は決済などウォレットを伴う操作に限る方向である。

Resonant アプリの利用先として、動画の締めくくりで Piブラウザ内のアプリが紹介されたが、正確なURLは字幕の聞き取りのみで確認できず、未確認である。

見出し：PI NEXT HACKATHON 2026／Pi Next に登録する

Pi Next ハッカソンへの参加登録を受け付けるページである。Pi Next は、開発者や作り手が Pi を使う新しいアプリを作るハッカソンである。登録すると、最新情報や資料、参加方法の案内が届く。

日程

  • 開始：2026年11月19日
  • 締め切り：2027年1月5日 23:59 PST（協定世界時では1月6日 07:59、日本時間では1月6日 16:59）

賞金総額：200,000 USDT

参加できる人：開発者、チーム、企業、スタートアップ

提出できるもの：最大3つのアプリ。対象はメインネットの Pi アプリと SoloHost アプリである。

Pi Next とは何か

世界中の開発者、スタートアップ、新しいものを生み出す人たちを招く、Pi Network の新しいハッカソンである。アプリは Pi の Developer Web Console（開発者向けのウェブ管理画面）か SoloHost で作り、6,000万人を超える Pi の活発な利用者に向けて公開して、200,000 USDT の賞金を競う。

審査と賞金

  1. 審査員賞：合計 50,000 USDT（1位 25,000 USDT、2位 15,000 USDT、3位 10,000 USDT）
  2. コミュニティ・エンゲージメント賞：合計 150,000 USDT、最大2チーム。審査員の評価と、実際の利用の広がり、利用者が使い続けるかどうか、コミュニティでの広がりの組み合わせで決まる。
  3. App Growth Initiative（アプリの成長を助ける仕組み）：最大2,000万 Pi が用意され、対象になるアプリが本物の利用者を集め、使い続けてもらうための、プラットフォーム公認の特典に使われる。これは賞金とは別の枠である。

何を作るか

テーマは自由である。人々の実際の困りごとに応える用途であれば何でもよい。ただし、メインネット掲載要件に従い、Pi のエコシステムに実際の役立ちをもたらすことが求められる。人々が使い続けるアプリを作り、Pi の認証（サインイン）と Pi 決済を組み込むこと。審査員は、アプリが利用者に何を提供するか、そして利用者が戻ってくるかどうかを見る。

詳しいルールは Pi Next の案内ページ（https://minepi.com/pi-next/）にある。
