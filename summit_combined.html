要約

Pi初のエコシステムサミット。AI支援の開発者コンソールとMCP、最大2,000万Piの成長支援、定期課金とx402決済の実証に加え、本人確認済みユーザーをAIの作業につなぐPi DataLab、SoloHostのAI包装スキル、CiDi Gamesの技術統合、Resonantとの対話を紹介した。

  • AI支援の開発者体験が中心であった。新しい開発者ウェブコンソールとMCPサーバーにより、AIコーディングエージェントがアプリの作成・登録、設定、Pi認証・Pi決済の組み込み、掲載申請までを代行する。創業者ニコラス・コッカリスによるデモでは、マルチプレイ対応の三目並べアプリを一から構築し、通知と決済（支払いと返金）までを通した。
  • Pi財団が資金を出す App Growth Initiative が発表された。予算は最大2,000万Piで、対象アプリは実績に応じてその一部を使い、KYC済みユーザーの獲得と参加を促す。参加条件と報酬額の詳細は後日発表される。
  • Piアプリ一覧（ディレクトリ）が刷新された。既存のステーキングによる順位付けを残しつつ、「ブックマーク」「ステーキング済み」「上昇中」「発見」「何度も戻ってくる」といった新しい区分が追加された。
  • Pi Launchpad、分散型取引所（DEX）、自動マーケットメーカー（AMM）は2027年第1四半期にメインネットへ移行する。Launchpadを通じた初のメインネットトークン発行も含まれる。
  • オンチェーン定期課金スマートコントラクトと x402 決済がテストネットで実証された。定期課金は2026年4月にテストネットへ初導入されたものである。x402 では OpenMind の RoboPay がロボットへの支払い（0.01テストPi）を実演した。
  • 本人確認済みのパイオニアをAIの作業につなぐ新しいプラットフォーム「Pi DataLab」が紹介された。企業やAI開発者は、データのラベル付けや評価など人間の判断を要する作業を依頼でき、参加したパイオニアは Pi またはトークンで報酬を受け取る。初版は完成しテスト環境で動作しており、公開されるパイロット版ではメインネットのウォレットを通じた決済がつながる見込みである。
  • SoloHost 向けの新しいAIスキルが実演された。既存アプリの公開Dockerイメージを示すと、AIエージェントが SoloHost への掲載に必要な2つの設定ファイルを生成し、検証まで行う。デモでは AIエージェントアプリ OpenClaw を例に、Pi Desktop 上での公開と動作までを示した。
  • CiDi Games の技術デモでは、Pi認証、Pi決済、Pi広告SDK、ローカルストレージの統合手順が示された。デモはローカルで動作する見本を用いたものであり、バックエンドによるアクセストークンの検証はまだ実装されていないことが明示された。
  • 創業者チェンディアオ・ファンとAIプロジェクト Resonant のジェイ氏による対話では、AIの判断を人間の判断と照らし合わせる検証層としての Resonant、データがAI経済の生産資源であること、Piの本人確認済みユーザー基盤の価値が語られた。
  • 移行・KYCに関する新たな発表は Day 1・Day 2 ともになかった。KYC完了ユーザー数は1,810万人超と紹介されたのみである。

サミットについて

Piエコシステムサミットは Pi Network 初の開発者向けサミットであり、2026年11月17日から19日までオンラインで開催される。Day 1（11月17日）のテーマは「開発者プラットフォーム、エコシステム施策、アプリ紹介」である。Day 1 の本編動画は Pi Network 公式YouTubeチャンネルでプレミア公開され、長さは1時間45分5秒である。Day 2（11月18日）は「AIとエコシステム」、Day 3（11月19日）は賞金20万USDTの新ハッカソン「Pi Next」のキックオフである。

開会の挨拶で創業者のチェンディアオ・ファンは、エコシステムの規模として、参加中のパイオニア6,000万人超、メインネットアプリ300超、ノード42万超、KYC完了ユーザー1,810万人超を紹介した。これらの数値は公式発表によるものである。

結果1：AI支援の開発者体験（開発者ウェブコンソールとMCP）

Day 1 の中心は、AIエージェントを使った開発者体験の刷新であった。新しいブラウザ型の開発者ウェブコンソール（developers.minepi.com）と、Piの開発者ツールに接続する MCP（Model Context Protocol）サーバーが導入された。対応するAIコーディングエージェントに自然言語で指示すると、アプリの作成と登録、設定とURLの構成、Pi認証やPi決済といった Pi API の組み込み、アプリ一覧への掲載申請までをエージェントが実行する。秘密情報（APIキーやウォレットの秘密鍵）はエージェントに見せない設計であり、必要な場面では人の承認が求められる。従来の手動の手順でも同じコンソールを使える。

創業者ニコラス・コッカリスによるデモでは、AIエージェントが三目並べゲーム「Pocket Grid」を一から構築した。デモで示された流れは次のとおりである。

  • エージェントがゲームを構築し、公開HTTPS URLへ展開した。開発当初は Pi との連携がない通常のアプリであった。
  • エージェントが Pi の MCP サーバーへ接続し、アプリを登録した。Pi Sandbox（Piブラウザを模した開発用環境）でアプリを読み込み、動作を検証した。
  • マルチプレイ機能を追加した。部屋を作成し、PiNet リンク（pinet.com で終わるURL）で友人を招待する。PiNet リンクを開くと Piブラウザでアプリが開く仕組みである。
  • 通知機能を追加した。手番が来た相手に通知を送る。サーバー間の通信には APIキー を使い、キーは開発者がコンソールで生成して安全な場所に保管する。
  • Pi決済を追加した。部屋の作成時に1 Piを支払い、誰も参加しなければ返金する流れを実演した。ユーザーからアプリへの支払いと、アプリからユーザーへの返金の両方向を示した。テストネットでの実演であり、アプリ側ウォレットの秘密鍵はエージェントに渡さず、開発者が保管した。
  • 最後にアプリ一覧への掲載申請の手順を示した。申請内容の多くはエージェントが事前に用意していた。

デモで示された所要時間は、マルチプレイまでの構築が約10分であった。ブログ記事も「従来は数日かかっていた手順が数分で済む」と説明している。

結果2：Pi DataLab（人間の判断をAIにつなぐ新プラットフォーム）

Pi DataLab は、企業・AI開発者・団体が、本人確認済みの世界中のパイオニアに、人間の判断を要する作業を依頼できる新しいヒューマン・イン・ザ・ループ型プラットフォームである。AIの学習・評価・改善に必要なデータ生成、ラベル付け、評価、順位付け、レビュー、フィジカルAI向けデータなど、人間の理解が要る作業が対象である。依頼側はプロジェクトを作成して資金を用意し、参加するパイオニアは自発的に作業を選び、判断や作業を提供して、完了した貢献に対して Pi またはトークンを受け取る。

デモでは、顧客対応チケットの感情分類（肯定的・中立的・否定的）を例に、プロジェクト作成から公開までの流れを示した。プロジェクト名「ticket sentiment」、作業ごとに5件の回答を求める設定、KYC済みであること・言語・地域などの参加条件を設定し、Piの審査を経て公開される。公開後は、作業の開始・完了までの平均時間や承認率などの指標を確認できる。作業者側にはタスクのマーケットプレイスが表示され、報酬と所要時間の目安を確認して作業を選ぶ。報酬は月払いである（デモ中の説明による）。

品質の仕組みとして、作業者の評判が記録される。努力の有無、作業の開始・完了にかかる時間、提出回数、正答率などが信号となり、質の維持と将来の作業の割り当てに使われる。

初版は完成し、テスト環境で動作している。デモはテスト環境で行われ、決済は有効化されていない。公開されるパイロット版では、メインネットのウォレットを通じた決済がつながる見込みである。公開時期は明示されていない。

背景として、PiのKYC検証の仕組みは、100万人超の本人確認済みの検証者が5億2,600万件超の検証作業を完了した実績がある（ブログ記事による）。ブログ記事は、報酬が法定通貨ではなく Pi を含むトークンで支払われる点を、従来のWeb2型プラットフォームとの違いとして説明している。

結果3：SoloHost のAIスキル（既存アプリの包装を自動化）

SoloHost は、開発者が自己ホスト型アプリを Pi Desktop へ持ち込み、42万人超のノード運営者と Pi Desktop 利用者に配布できる仕組みである。Dockerイメージとして包装できる作業負荷であれば、SoloHost 上で動作する可能性がある。新しいAIスキルは、この包装作業をAIエージェントに任せるためのものであり、公開リポジトリ（github.com/pi-node/solohost）で提供されている。対応するAIエージェント（Claude Code、Cursor、Codexなど）に既存アプリの公開Dockerイメージを示すと、エージェントがアプリの機能を調べ、必要な設定を尋ね、包装に必要な2つのファイル（docker-compose.yml と config_options.yml）を生成し、SoloHost の検証プログラムで確認する。イメージ自体の構築はスキルでは行わない。

デモでは、AIエージェントアプリ OpenClaw を例に、スキルが3つのモデル提供者（Anthropic、OpenAI、OpenRouter）と Telegram 連携、DuckDuckGo によるウェブ検索などの機能を調べ、利用者が選んだ機能だけを反映した2つのファイルを生成し、検証プログラムの指摘を自ら修正したうえで、ローカルでの動作確認まで行う流れを示した。生成した2つのファイルを SoloHost へ貼り付けて公開すると、Pi Desktop 上でアプリが動作し、天気の質問に回答した。

結果4：オンチェーン定期課金と x402 決済（テストネットでの実証）

オンチェーン定期課金スマートコントラクト

Piのオンチェーン定期課金スマートコントラクトは、アプリに継続課金機能を組み込むための仕組みである。2026年4月にテストネットへ初導入された。利用者は、定額の利用枠と課金期間（例：月額課金で6か月分）を承認するだけで、毎回の更新に署名する必要はない。承認した資金は課金が実行されるまで利用者自身のウォレットに残り、前払いで拘束されない。利用者は承認枠の延長や解約ができる。契約のデータは2つの記録（サービス内容と利用者ごとの契約状態）で管理され、チェーン上に約180日間保持される。

Day 1 のデモでは、月額2 Piのサービスを作成し（サービスID 332）、利用者が契約してウォレット側で契約状態を確認する流れを示した。デモ中の例では、次回課金は12月10日から1月10日の期間に加盟店が処理できることになっていた。定期課金は現時点ではテストネット限定である。ウォレットと開発者プラットフォーム側の関連機能も整備され、利用者と開発者の双方が使える形になったとブログ記事は説明している。

x402 決済のテストネット統合

x402 は、HTTP の 402（Payment Required）応答を使う公開の決済手順である。サーバーが価格・資産・支払先を示し、利用者側が支払い承認に署名して再送すると、仲介者（ファシリテーター）が承認を確認してチェーンへ提出する。資金は支払者から受取先へ直接1回のオンチェーン取引で移動し、仲介者が資金を預かることはない。Coinbase が策定し、x402 Foundation が管理する公開規格である。

Pi は x402 決済を Piテストネットで使えるようにした。Day 1 では OpenMind が Fabric Foundation と共同で開発した RoboPay の実演があった。ロボットへの ping 送信の前に 0.01 テストPi を支払い、支払い完了後にコマンドが届く流れを示した。ネットワーク手数料はスポンサー負担であり、支払者の残高変動はちょうどマイナス0.01テストPiであった。PiのネットワークID（pinet）は Chain Agnostic の登録簿に統合済みであり、Piの x402 支払い仕様は公式 x402 リポジトリで審査中である。仕様はテストネットとメインネットの双方を対象とするが、メインネットでの利用開始時期は今後共有される。仕様を実装する Go SDK も用意されている。

結果5：エコシステム施策（成長支援、アプリ一覧、Launchpad）

App Growth Initiative（最大2,000万Pi）

Pi財団が資金を出す新しい取り組み「App Growth Initiative」が発表された。予算は最大2,000万Piである。対象となる開発者は、アプリの質・実用性・利用実績に応じて予算の一部を使える。開発者は自ら報酬を用意せずに、KYC済みユーザーを獲得し、参加を促す仕組みを利用できる。例として、KYC済みのパイオニアが別のKYC済みパイオニアを対象アプリへ招待した場合、紹介者と新規利用者の双方が財団の予算から Pi を受け取れる場合があることが示された。参加条件と報酬額の詳細は後日発表される。

Piアプリ一覧の刷新

Piアプリ一覧（ディレクトリ）が大幅に刷新された。従来の「エコシステム・ディレクトリ・ステーキング」（Piを預けてアプリを応援し順位に反映する仕組み）は中心的な仕組みとして残る。そのうえで、関心・成長・利用実績に基づく新しい区分が追加された。

区分内容
ブックマークしたアプリお気に入りのアプリへ戻りやすくする
Piをステーキングしたアプリ従来のコミュニティによるステーキング順位を維持する
上昇中のアプリ勢いのある新しいアプリを紹介する
発見まだ試していないアプリを紹介する
何度も戻ってくる繰り返し利用されているアプリを紹介する

開発者への動機付けは、露出・資金支援・評価の3つで構成される。資金支援の一例として、Pi App Studio の料金は、実際の利用と実用性を示す開発者には割引価格が適用される。評価としては、アプリ一覧にアプリや開発者の状態が表示されるほか、優れたアプリは Pi Network Ventures からの投資や Launchpad の候補になる機会がある。

Pi Launchpad、DEX、AMM の2027年第1四半期メインネット化

Pi Launchpad、分散型取引所（DEX）、自動マーケットメーカー（AMM）は2027年第1四半期にメインネットへ移行する。テストネットで複数回の改良を重ねたものであり、Launchpadを通じた初のメインネットトークン発行も含まれる。エコシステム内の特定の用途向けトークンの発行基盤となる。ハッカソン「Pi Next」の参加者にも、トークン発行に向けた準備期間が与えられる。

その他の開発者向け機能

  • PiNetリンクの改善：PiNetリンクを受け取った人が Piブラウザ未導入の場合、アプリストア等から Piブラウザを導入するよう案内され、導入後に元のアプリやページへ直接案内される。招待された人が迷わず遊べるようになり、離脱が減る。
  • 通知センター：アプリから利用者へ Piブラウザ内で通知を送れる仕組みである。携帯電話へのプッシュ通知ではなく、Piブラウザ内に通知がまとめて表示される。導入初期は承認なしで最大20人まで通知でき、それ以上は承認が必要である。ネイティブのプッシュ通知は次の段階であり、迷惑通知を防ぐため限定的な条件が付く。

結果6：CiDi Games（開発者対話と技術デモ）

Day 1 の後半では、創業者チェンディアオ・ファンと CiDi Games 共同創業者のジェレミー氏による対話があった。CiDi Games は Piブラウザ内で直接遊べる HTML5 ゲームプラットフォームであり、Piエルフという独自キャラクターと、その世界「エルフ大陸」を展開している。公開から約6か月が経過し、ベータ版のまま運営されている。

CiDi Games が示した実績は次のとおりである（同社の発表による）。

項目数値
公開中のゲーム数約70本（月約10本を追加）
アカウント数35万超
1日あたりの利用者数約4万人
エルフ大陸の1日あたりの利用者数約3万人
150日目の定着率20〜30%
累計ゲームセッション数1,000万超
累計広告表示回数約2,500万回
エルフ大陸での累計滞在時間600万時間超
他者の土地への訪問回数400万回超
マーケットでの取引回数200万回超

CiDi Games の今後の方向性として、Piエルフの画像素材を外部の開発者に開放し、ブロックチェーン上で NFT として対応づけること、NFT の発行所や売買所といった開発者向け道具の整備、独自トークンの Launchpad への上場が語られた。ただし、これらは同社の社内での方向性であり、独自トークンについては Pi Core Team との協議前であることが対話の中で明言された。確定した発表ではない。

また、CiDi Games は Pi Core Team との協力例として、KYCに関する質問が利用者から寄せられたことを報告し、KYC調査の質問票が2週間以内に整備・開始されたことを紹介した。iOS利用者の保存領域の問題への対応や、メインネット審査の迅速化、広告枠のチーム別集計といった改善も、開発者からの要望を受けて行われたと述べた。

ファンは今後の戦略として、外部の需要と Pi の共有資源（配布・注目・利用者獲得、利用者の同意を得た上での人の関与による作業やデータ、分散コンピューティング、本人確認）を結びつける方針を説明した。ゲームは Pi と相性が良い分野であり、決済・交流・金融参加への入り口になると述べた。ステーブルコインの統合や追加の Web3 機能も、Pi通貨の中心的な役割を損なわない範囲で検討されている。

対話に続き、CiDi Games のゲームプラットフォームが Pi の開発者ツールとどのように統合されるかを、技術デモで示した。対象は Pi認証（サインイン）、Pi決済、Pi広告SDK、ローカルストレージである。デモは、実際の本番環境ではなく、ローカルで動作する見本（サンプル）を用いて、公式SDKの手順をなぞる形で行われた。見本であることは動画の中で繰り返し明示されている。

認証では、ユーザー名と決済の範囲を要求し、Piの認証結果（アクセストークンとユーザー情報）を受けて、アプリ側のアカウントと結びつける流れを示した。Piのユーザー識別子はアプリごとに異なるものであり、すべてのアプリで共通の識別子ではないこと、権限を取り消すと変わり得ることが説明された。重要な点として、CiDi Games の現在のバックエンドは、アクセストークンを Pi に問い合わせて検証する手順をまだ実装しておらず、公式の推奨手順（トークンをバックエンドへ送り、Pi へユーザー情報を問い合わせて照合する）とは区別して示された。本番環境で検証が行われているという主張ではない。

決済では、プラットフォーム通貨 CDcoin へのチャージを例に、100コインのチャージ（残高101から201へ）を示した。決済の承認・完了・重複防止の各段階を区別し、完了が確認されて初めてコインを付与すること、ブラウザを閉じて決済が中断した場合には未完了の決済を照会して回収する仕組みが説明された。表示された Pi の金額は見本の目安であり、実際の為替相場ではない。

広告では、リワード広告を例に、見逃した毎日のチェックインを広告視聴で補う流れを示した。広告の視聴だけでは報酬は付与されず、バックエンドが Pi へ広告の状態を問い合わせ、仲介者の承認状態（mediator acknowledgement status）が「granted」である場合にのみ報酬が付与される。保留中（pending）や取り消し・失敗では付与されない。広告識別子は一度だけ有効であり、重複請求は防がれる。

ローカルストレージでは、言語設定（英語から日本語への切り替え）を例に、設定がブラウザに保存され、再起動後に復元されることを示した。端末ごとの保存であり、端末間の同期や恒久的な保存を保証するものではない。また、CiDi Games のローカルストレージ利用の承認（ホワイトリスト）状態は未確認であり、動画の中でも確認が必要であることが明言された。

共有のゲームSDKと共通の検証サービスにより、複数のゲームが同じ統合の仕組みを使い回す設計も説明された。例として Meme War と Ian Reap が挙げられた。ただし、両タイトル名の表記は字幕のみが根拠であり、公式資料での裏付けはできていない。

結果7：開発者対話（Resonant）― AIとデータの経済における人間の参加

創業者チェンディアオ・ファンと、AIプロジェクト Resonant のジェイ氏による対話があった。Resonant は、AIの判断を人間の判断と照らし合わせるための検証層である。人間が倫理的なジレンマ（例：家庭用ロボットが火災時に誰を助けるか）に対して下す判断と、その判断のデータを集め、AIエージェントが人間の判断と一致しているかを測る。現在までに約170万件の判断が集まっており、1,500万件に達すればデータがさらに価値を持つと説明された（発言のみが根拠）。

対話では、データがAI経済における重要な生産資源であること、Pi DataLab がその需要とパイオニアをつなぐ役割を果たすこと、AIエージェントが Pi Desktop 上で動作する SoloHost や Piアプリとして配布できること、Piの本人確認済みユーザー基盤が、AI企業にとって人間の証明とオンボーディングの障壁を下げる価値があることが語られた。Resonant が Pi を選んだ理由として、世界中のユーザーへの露出と、ワンクリックでの本人確認済みログインによる利用者獲得コストの低さが挙げられた。

また、開発者への助言として、アプリを英語のみで書くと利用者の約40%にしか届かず、ネイティブ翻訳により利用者の取り込みが2〜3倍になるという経験が紹介された（発言のみが根拠）。Piの利用者は9言語を使っていると説明された。

Resonant の今後の方向性として、質問を動画形式で提示するなど、楽しさを伴う形で判断データを集めることが語られた。利用者は自分の判断プロフィール（自分のデータ）を持ち、エージェントと結びつけたり、将来的にはデータの収益化の仕組みにつなげたりすることが想定されている。現在の Resonant は非営利の研究用検証層であり、データは詳細を含まず公開されている。

ファンは、テストネットとメインネットの区別をアプリ一覧の掲載手続きから切り離す方針を説明した。アプリの掲載は一覧の手続きとして簡素化し、テストネット／メインネットの区別は決済などウォレットを伴う操作に限る方向である。

Resonant アプリの利用先として、動画の締めくくりで Piブラウザ内のアプリが紹介されたが、正確なURLは字幕の聞き取りのみで確認できず、未確認である。
