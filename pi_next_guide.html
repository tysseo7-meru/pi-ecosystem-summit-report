Pi Next とは

Pi Next は、Pi Network のまったく新しいハッカソン（短期間にアプリを作り競う催し）である。世界中の開発者、スタートアップ、新しいものを生み出す人たちが招かれている。AI コーディングエージェント（プログラムを書くAI）の助けを借りて Pi のアプリを作り、6,000万人を超える Pi の活発な利用者に向けて公開して、賞金総額200,000 USDT（米ドルと連動するデジタル通貨）を競う。賞金とは別に、最大2,000万 Pi のマーケティング支援（アプリの利用者を増やすための支援）も用意されている。

Pi Network は、レイヤー1ブロックチェーン（土台となるブロックチェーン）であり、開発者向けの基盤である。何千万人もの利用者が Pi をマイニング（Pi アプリで Pi を得ること）し、Pi のアプリやサービスの集まりの中で Pi を使っている。Pi は、本人確認済みの本物の利用者の世界的な集まりと、開発者や事業者をつなぐ。アプリを作る側には、利用者の広がり、本人確認済みの身元、国境を越えて使える規模の大きな決済、そして利用者を集めて使い続けてもらうための道具を提供する。

アプリの作り方は2通りある。1つは Developer Web Console（開発者向けのウェブ管理画面）で Pi アプリを作る方法である。この管理画面は AI コーディングエージェントに対応しており、アプリの作成・設定・登録・組み込みを手伝う。Pi の認証（サインイン）や Pi 決済などの道具も使える。もう1つは SoloHost で作る方法である。SoloHost は Pi Desktop（パソコン向けの Pi のアプリ）の中の仕組みで、作り手が自分のアプリやノード（Pi のネットワークに参加しているパソコン）向けの道具を、許可を取らずに公開できる流れで出せる。42万人を超えるノードや Pi Desktop の利用者に届く。利用者は、自分で見つけて、評価し、導入して、自分のパソコンで動かす。SoloHost のアプリには、自分のパソコンで動く AI エージェントのような自己ホスト型（自分のパソコンで動かす形）のアプリや、AI の学習・推論のような分散コンピューティング（多くのパソコンで計算を分け合うこと）の用途がある。

賞金と支援

賞金総額 200,000 USDT

賞金は次の2つに分かれる。最大2,000万 Pi のマーケティング支援は、この賞金とは別の枠である。

審査員賞：合計 50,000 USDT

  • 1位：25,000 USDT
  • 2位：15,000 USDT
  • 3位：10,000 USDT

審査基準は次のとおりである。

  • メインネット掲載ガイドラインとの適合。SoloHost アプリは、Pi アプリと同じ水準の質・機能・有用性が求められるが、SoloHost 側の掲載要件に従う
  • Pi の有用性と、コミュニティとエコシステム全体のニーズとの適合
  • 技術的な完成度と革新性
  • UI/UX（画面の見た目と使い勝手）、誰でも使いやすいこと、画面移動のしやすさ
  • Pi メインネットのブロックチェーンでの長期的な有用性
  • 独自性と、ほかにはない用途

コミュニティ・エンゲージメント賞：合計 150,000 USDT

最大2チームに贈られる。審査員の評価と、実際の利用の広がり、利用者が使い続けるかどうか、コミュニティでの広がりの組み合わせで決まる。

マーケティング支援：最大2,000万 Pi（賞金とは別枠）

Pi 財団が最大2,000万 Pi を用意したもので、対象になるアプリが本物の利用者を集め、使い続けてもらうための支援である。App Growth Initiative（アプリの成長を助ける仕組み）の枠組みであり、プラットフォーム公認の特典を通して、対象アプリを使う・紹介した対象のパイオニアが Pi 報酬を受け取れる場合がある。開発者は自分の資金を使わずに利用者を増やし、新しい利用者に知ってもらう利益を得られる。

アプリの作り方

Pi アプリの作り方

  1. Pi アカウントを作る。Pi Browser（Pi のアプリを使うためのブラウザ）をダウンロードして始める。
  2. Developer Web Console の Hackathon タブで Pi Next に登録する。チーム全員が登録しないと、参加・賞金対象にならない。
  3. Developer Web Console の案内に従って Pi アプリを作る。
  4. 任意：中間提出に参加する。詳細は、Developer Web Console で Pi Next に登録した参加者全員にメールで連絡される。選ばれたアプリは、追加で知ってもらえる機会と、最終提出の締め切り前にアプリを良くするための助言を受けられる。
  5. 2027年1月5日（火）23:59 PST（日本時間1月6日（水）16:59）までに、Developer Web Console からアプリを提出する。提出は、チームの中で1人だけが行う。

SoloHost アプリの作り方

  1. Pi アカウントを作る。Pi Browser をダウンロードして始める。
  2. Developer Web Console の Hackathon タブで Pi Next に登録する。チーム全員が登録しないと、参加・賞金対象にならない。
  3. Pi Desktop を自分のパソコンにダウンロードして導入する。
  4. アプリを作り、Pi Desktop の SoloHost から公開する。公開されている SoloHost の GitHub リポジトリにある AI スキル（AIに特定の作業をさせるための手順書のようなもの）を使うと、AI コーディング助手に公開の準備を手伝わせられる。
  5. 任意：中間提出に参加する。詳細は登録者全員にメールで連絡される。選ばれたアプリは、追加で知ってもらえる機会と、最終提出の締め切り前にアプリを良くするための助言を受けられる。
  6. 2027年1月5日（火）23:59 PST（日本時間1月6日（水）16:59）までに、Developer Web Console から提出する。提出は、チームの中で1人だけが行い、案内された欄に SoloHost App ID（SoloHost で発行されるアプリの番号）を入力する。

どんなアプリを作れるか

テーマは自由（オープンエンド）である。開発者、企業、作り手が自分の考えを形にする自由がある。人々の実際の困りごとに応える用途であれば何でもよい。ただし、メインネット掲載要件に従い、Pi のエコシステムに実際の役立ちをもたらすことが求められる。人々が使い続けるアプリを作り、Pi の認証（サインイン）や Pi 決済といった Pi の組み込み機能を使うこと。審査員は、アプリが利用者に何を提供するか、そして利用者が戻ってくるかどうかを見る。

Pi が用意しているもの

Pi は、本人確認済みの世界中の利用者の集まりから、何百万人もの利用者に広がるために必要なものをアプリに提供する。内容は「作る」「つなぐ」「収益にする」「広める」の4つに分かれる。

作る

  • Developer Web Console と AI コーディングエージェント（MCP）：ウェブで使える開発者向けの新しい基盤で、自分の選んだ AI コーディングエージェントに、アプリの作成・登録・設定・組み込みを手伝わせられる。MCP は Model Context Protocol の略で、AIが外部の道具やサービスにつながるための共通の取り決めである。管理画面で Pi の認証と Pi 決済を加えられる。これまでの開発者、AI の助けを借りる作り手、雰囲気で作る人（バイブコーダー）でも、新しいアプリを作ったり、今あるアプリを Pi に持ってきたりしやすくなる。
  • SoloHost のパッケージ化スキル：AI コーディング助手に、今あるアプリの公開準備を手伝わせられる。設定ファイルを自分で書かなくても、自分のアプリを Pi Desktop の利用者に提供できる。

つなぐ

  • Pi の認証（サインイン）：利用者は今持っている Pi アカウントでアプリにログインでき、新しいユーザー名とパスワードを作らなくてよい。作り手は自前のログインの仕組みを作らなくてよく、利用者が入りやすくなり、利用開始につながりやすい。
  • Pi の SDK（開発キット）、説明書、デモアプリ：Pi の認証と Pi 決済の加え方を示している。Developer Web Console 経由で AI コーディングエージェントに加えさせることもできる。

収益にする

  • Pi Ad Network（Pi の広告の仕組み）：対象になるアプリは、報酬型広告（見ると報酬が出る広告）とインタースティシャル広告（画面いっぱいに表示される広告）を、アプリの流れと利用者の動きに合わせて入れられる。
  • Pi 決済：アプリは利用者に Pi で請求したり、世界中の利用者に Pi を払ったりできる。すべての取引は作り手のサーバーで確認され、Pi のブロックチェーンに記録され、Pi BlockExplorer（取引を調べる公式サイト）で確認できる。
  • 定期課金のスマートコントラクト（条件を満たすと自動で実行されるプログラム）：会員制や有料サービスのような定期課金の仕組みを Pi のブロックチェーン上に作れる。利用者が支払いのたびに承認したり、全額を前もって送ったりしなくてよい。現在は Pi テストネット（試作用のネットワーク）で使える状態であり、組み込みを始められる。

広める

  • エコシステム・アプリ・ディレクトリ：Pi Browser の中にあるアプリ一覧で、条件を満たしたメインネットのアプリが載り、何百万人もの Pi 利用者に見つけてもらえる。作り手は Pi をステーキング（預けておくこと）したり、コミュニティを動かしたりして、一覧での順位を上げられる。
  • 通知センター：作り手は自分のアプリの利用者に通知を送れ、利用者の動きや更新を直接知らせることで、使われ続けることにつなげられる。
  • PiNet：作り手はアプリ体験の一部を Pi のエコシステムの外の利用者にも開ける。Pi Browser を入れていない人や、普通のウェブブラウザで試すよう招待された人にも使ってもらえる。
