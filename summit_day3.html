結果12：Pi Next（ハッカソン「Pi Next」のキックオフ）

Pi Next は、開発者や作り手が Pi を使う新しいアプリを作るハッカソンである。2026年11月19日に始まった。Pi の Developer Web Console か SoloHost でアプリを作り、6,000万人を超える Pi の利用者に向けて公開して、賞金20万USDTを競う。参加できるのは開発者、チーム、企業、スタートアップである。

賞金と支援

賞金総額は20万USDTである。内訳は次の2つで、混同しないこと。最大2,000万Piのマーケティング支援は、賞金とは別の枠である。

区分内容
審査員賞（合計5万USDT）1位 2万5,000 USDT、2位 1万5,000 USDT、3位 1万 USDT
コミュニティ・エンゲージメント賞（合計15万USDT）最大2チーム。審査員の評価と、実際の利用の広がり、利用者が使い続けるかどうか、コミュニティでの広がりの組み合わせで決まる
App Growth Initiative（最大2,000万Pi、賞金とは別枠）Pi 財団が用意したマーケティング支援。対象になるアプリが本物の利用者を集め、使い続けてもらうための、プラットフォーム公認の特典に使われる。対象アプリを使う・紹介したパイオニアに Pi 報酬が出る仕組みである

審査員賞の審査基準は、メインネット掲載ガイドラインとの適合、Pi の有用性・コミュニティのニーズとの適合、技術的な完成度と革新性、UI/UX（画面の使いやすさ）・使いやすさ、メインネットでの長期的な有用性、独自性である。SoloHost アプリは、Pi アプリと同じ水準の質・機能・有用性が求められるが、SoloHost 側の掲載要件に従う。

参加方法（2つの作り方）

  • Pi アプリ：Pi アカウントを作り、Developer Web Console（開発者向けのウェブ管理画面）の Hackathon タブで Pi Next に登録する。チーム全員が登録しないと参加・賞金対象にならない。コンソールの案内に従ってアプリを作る。
  • SoloHost アプリ：Pi アカウントを作り、Developer Web Console の Hackathon タブで Pi Next に登録する（チーム全員が登録すること）。Pi Desktop を自分のパソコンに導入し、SoloHost でアプリを作って公開する。SoloHost の GitHub にある AI スキル（AIに特定の作業をさせるための手順書のようなもの）を使って、AI コーディング助手（プログラムを書くAI）に準備を手伝わせる。提出時に SoloHost App ID を入力する。

何を作るか・提出物

テーマは自由である。人々の実際の困りごとに応える用途であれば何でもよい。ただし、メインネット掲載要件に従い、Pi のエコシステムに実際の役立ちをもたらすことが求められる。人々が使い続けるアプリを作り、Pi の認証（サインイン）と Pi 決済を組み込むこと。審査員は、アプリが利用者に何を提供するか、そして利用者が戻ってくるかどうかを見る。提出できるアプリは最大3つまでである（登録ページによる）。

提出は Developer Web Console から行い、デモ動画（3分以内、YouTube などに公開）とチームメンバー一覧を含める。動画では「アプリが何をするか」「機能と画面の説明」「誰のためか」「どんな困りごとを解決するか」「Pi がどう関わるか（サインインや決済）」を説明する。すべてのアプリに必要なものは、英語の名前、Pi の商標ガイドラインに従ったロゴ、正確な英語の説明、画面のプレビュー画像、PiNet との連携、プライバシーポリシーである。SoloHost アプリは SoloHost の公開要件にも従う。
