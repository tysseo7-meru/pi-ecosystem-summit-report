要約

Pi初のエコシステムサミット初日。AI支援の開発者コンソールとMCP（AIエージェントと開発ツールをつなぐ仕組み）、最大2,000万Piの成長支援、アプリ一覧刷新、Launchpad等の2027年第1四半期メインネット化、定期課金とx402決済を実証した。

  • AI支援の開発者体験が中心であった。新しい開発者ウェブコンソール（開発者がアプリを登録・管理する画面）とMCPサーバー（AIエージェントが開発ツールを使うための接続の仕組み）により、AIコーディングエージェント（プログラミング作業を代行するAI）がアプリの作成・登録、設定、Pi認証・Pi決済の組み込み、掲載申請までを代行する。創業者ニコラス・コッカリスによるデモでは、マルチプレイ対応の三目並べアプリを一から構築し、通知と決済（支払いと返金）までを通した。
  • Pi財団が資金を出す App Growth Initiative が発表された。予算は最大2,000万Piで、対象アプリは実績に応じてその一部を使い、本人確認（KYC）済みユーザーの獲得と参加を促す。参加条件と報酬額の詳細は後日発表される。
  • Piアプリ一覧（ディレクトリ）が刷新された。既存のステーキング（Piを預けてアプリを応援する仕組み）による順位付けを残しつつ、「ブックマーク」「ステーキング済み」「上昇中」「発見」「何度も戻ってくる」といった新しい区分が追加された。
  • Pi Launchpad（新しいトークンの発行を支援する場）、分散型取引所（DEX、利用者同士が直接コインを交換する取引所）、自動マーケットメーカー（AMM、自動で価格を決めて交換を成立させる仕組み）は2027年第1四半期にメインネットへ移行する。Launchpadを通じた初のメインネットトークン（ブロックチェーン上で発行される独自のコイン）発行も含まれる。
  • オンチェーン（ブロックチェーン上に記録される形）の定期課金スマートコントラクト（条件を満たすと自動で実行されるプログラム）と x402 決済（ウェブ上で料金を支払うための決済手順）がテストネット（本番前の試験用ネットワーク）で実証された。定期課金は2026年4月にテストネットへ初導入されたものである。x402 では OpenMind の RoboPay がロボットへの支払い（0.01テストPi）を実演した。
  • 移行・KYCに関する新たな発表は Day 1 にはなかった。KYC完了ユーザー数は1,810万人超と紹介されたのみである。

サミットと Day 1 の位置づけ

Piエコシステムサミットは Pi Network 初の開発者向けサミットであり、2026年11月17日から19日までオンラインで開催される。Day 1（11月17日）のテーマは「開発者プラットフォーム、エコシステム施策、アプリ紹介」である。Day 1 の本編動画は Pi Network 公式YouTubeチャンネルでプレミア公開（決まった日時に初めて公開する形式）され、長さは1時間45分5秒である。Day 2（11月18日）は「AIとエコシステム」、Day 3（11月19日）は賞金20万USDTの新ハッカソン（開発者が短期間にアプリを作り競う催し）「Pi Next」のキックオフである。

開会の挨拶で創業者のチェンディアオ・ファンは、エコシステムの規模として、参加中のパイオニア6,000万人超、メインネットアプリ300超、ノード（ネットワークを支える参加者のコンピュータ）42万超、KYC完了ユーザー1,810万人超を紹介した。これらの数値は公式発表によるものである。

結果1：AI支援の開発者体験（開発者ウェブコンソールとMCP）

Day 1 の中心は、アプリ作りの面倒な手順をAIエージェント（作業を代行するAI）に任せる仕組みであった。新しいブラウザ型の開発者ウェブコンソール（developers.minepi.com、開発者がアプリを登録・管理する画面）と、Piの開発者ツールに接続する MCP（Model Context Protocol、AIエージェントが外部のツールを使うための共通の接続規格）サーバーが導入された。対応するAIコーディングエージェントに自然言語（ふだんの言葉）で指示すると、アプリの作成と登録、設定とURLの構成、Pi認証（Piアカウントでログインする仕組み）やPi決済といった Pi API（外部のプログラムからPiの機能を呼び出す窓口）の組み込み、アプリ一覧への掲載申請までをエージェントが実行する。秘密情報（APIキーやウォレットの秘密鍵）はエージェントに見せない設計であり、必要な場面では人の承認が求められる。従来の手動の手順でも同じコンソールを使える。

創業者ニコラス・コッカリスによるデモでは、AIエージェントが三目並べゲーム「Pocket Grid」を一から構築した。デモで示された流れは次のとおりである。

  • エージェントがゲームを構築し、公開HTTPS URL（インターネット上で公開される住所）へ展開（公開）した。開発当初は Pi との連携がない通常のアプリであった。
  • エージェントが Pi の MCP サーバーへ接続し、アプリを登録した。Pi Sandbox（Piブラウザを模した開発用環境）でアプリを読み込み、動作を検証した。
  • マルチプレイ（複数人で同時に遊ぶ）機能を追加した。部屋を作成し、PiNet リンク（pinet.com で終わるURL）で友人を招待する。PiNet リンクを開くと Piブラウザでアプリが開く仕組みである。
  • 通知機能を追加した。手番が来た相手に通知を送る。サーバー間の通信には APIキー を使い、キーは開発者がコンソールで生成して安全な場所に保管する。
  • Pi決済を追加した。部屋の作成時に1 Piを支払い、誰も参加しなければ返金する流れを実演した。ユーザーからアプリへの支払いと、アプリからユーザーへの返金の両方向を示した。テストネットでの実演であり、アプリ側ウォレットの秘密鍵はエージェントに渡さず、開発者が保管した。
  • 最後にアプリ一覧への掲載申請の手順を示した。申請内容の多くはエージェントが事前に用意していた。

デモで示された所要時間は、マルチプレイまでの構築が約10分であった。ブログ記事も「従来は数日かかっていた手順が数分で済む」と説明している。

結果2：定期課金と x402 決済（テストネットでの実証）

オンチェーン定期課金スマートコントラクト

これは、月額制のような定期払いをアプリに組み込むための仕組みである。Piのオンチェーン（ブロックチェーン上に記録・実行される）定期課金スマートコントラクト（あらかじめ決めた条件で自動的に実行されるプログラム）がそれにあたる。2026年4月にテストネットへ初導入された。利用者は、定額の利用枠と課金期間（例：月額課金で6か月分）を承認するだけで、毎回の更新に署名（承認の操作）をする必要はない。承認した資金は課金が実行されるまで利用者自身のウォレットに残り、前払いで拘束されない。利用者は承認枠の延長や解約ができる。契約のデータは2つの記録（サービス内容と利用者ごとの契約状態）で管理され、チェーン上に約180日間保持される。

Day 1 のデモでは、月額2 Piのサービスを作成し（サービスID 332）、利用者が契約してウォレット側で契約状態を確認する流れを示した。デモ中の例では、次回課金は12月10日から1月10日の期間に加盟店（サービスを提供する側）が処理できることになっていた。定期課金は現時点ではテストネット限定である。ウォレットと開発者プラットフォーム側の関連機能も整備され、利用者と開発者の双方が使える形になったとブログ記事は説明している。

x402 決済のテストネット統合

x402 は、HTTP の 402（Payment Required）応答を使う公開の決済手順である。サーバーが価格・資産・支払先を示し、利用者側が支払い承認に署名して再送すると、仲介者（ファシリテーター）が承認を確認してチェーンへ提出する。資金は支払者から受取先へ直接1回のオンチェーン取引で移動し、仲介者が資金を預かることはない。Coinbase が策定し、x402 Foundation が管理する公開規格である。

Pi は x402 決済を Piテストネットで使えるようにした。Day 1 では OpenMind が Fabric Foundation と共同で開発した RoboPay の実演があった。ロボットへの ping（呼びかけの信号）送信の前に 0.01 テストPi を支払い、支払い完了後にコマンドが届く流れを示した。ネットワーク手数料はスポンサー（第三者）負担であり、支払者の残高変動はちょうどマイナス0.01テストPiであった。PiのネットワークID（pinet）は Chain Agnostic（チェーンを問わず共通に使うネットワーク識別子の登録簿）に統合済みであり、Piの x402 支払い仕様は公式 x402 リポジトリで審査中である。仕様はテストネットとメインネットの双方を対象とするが、メインネットでの利用開始時期は今後共有される。仕様を実装する Go SDK（Go言語用の開発キット）も用意されている。

結果3：エコシステム施策（成長支援、アプリ一覧、Launchpad）

App Growth Initiative（最大2,000万Pi）

これは、良いアプリに利用者を集めるための費用を、開発者の代わりにPi財団が出す仕組みである。Pi財団が資金を出す新しい取り組み「App Growth Initiative」が発表された。予算は最大2,000万Piである。対象となる開発者は、アプリの質・実用性・利用実績に応じて予算の一部を使える。開発者は自ら報酬を用意せずに、KYC済みユーザーを獲得し、参加を促す仕組みを利用できる。例として、KYC済みのパイオニアが別のKYC済みパイオニアを対象アプリへ招待した場合、紹介者と新規利用者の双方が財団の予算から Pi を受け取れる場合があることが示された。参加条件と報酬額の詳細は後日発表される。

Piアプリ一覧の刷新

Piアプリ一覧（ディレクトリ）が大幅に刷新された。従来の「エコシステム・ディレクトリ・ステーキング」（Piを預けてアプリを応援し順位に反映する仕組み）は中心的な仕組みとして残る。そのうえで、関心・成長・利用実績に基づく新しい区分が追加された。

区分内容
ブックマークしたアプリお気に入りのアプリへ戻りやすくする
Piをステーキングしたアプリ従来のコミュニティによるステーキング順位を維持する
上昇中のアプリ勢いのある新しいアプリを紹介する
発見まだ試していないアプリを紹介する
何度も戻ってくる繰り返し利用されているアプリを紹介する

開発者への動機付けは、露出・資金支援・評価の3つで構成される。資金支援の一例として、Pi App Studio の料金は、実際の利用と実用性を示す開発者には割引価格が適用される。評価としては、アプリ一覧にアプリや開発者の状態が表示されるほか、優れたアプリは Pi Network Ventures からの投資や Launchpad の候補になる機会がある。

Pi Launchpad、DEX、AMM の2027年第1四半期メインネット化

Pi Launchpad、分散型取引所（DEX）、自動マーケットメーカー（AMM）は2027年第1四半期にメインネットへ移行する。これらは、新しいトークンの発行や、利用者同士のコインの交換を、Piの本番ネットワーク（メインネット）上で行えるようにする基盤である。テストネットで複数回の改良を重ねたものであり、Launchpadを通じた初のメインネットトークン発行も含まれる。エコシステム内の特定の用途向けトークンの発行基盤となる。ハッカソン「Pi Next」の参加者にも、トークン発行に向けた準備期間が与えられる。

その他の開発者向け機能

  • PiNetリンクの改善：PiNetリンクを受け取った人が Piブラウザ未導入の場合、アプリストア等から Piブラウザを導入するよう案内され、導入後に元のアプリやページへ直接案内される。招待された人が迷わず遊べるようになり、離脱が減る。
  • 通知センター：アプリから利用者へ Piブラウザ内で通知を送れる仕組みである。携帯電話へのプッシュ通知ではなく、Piブラウザ内に通知がまとめて表示される。導入初期は承認なしで最大20人まで通知でき、それ以上は承認が必要である。ネイティブのプッシュ通知（スマートフォンの画面に直接届く通知）は次の段階であり、迷惑通知を防ぐため限定的な条件が付く。

結果4：開発者対話（CiDi Games）

Day 1 の後半では、創業者チェンディアオ・ファンと CiDi Games 共同創業者のジェレミー氏による対話があった。CiDi Games は Piブラウザ内で直接遊べる HTML5 ゲームプラットフォームであり、Piエルフという独自キャラクターと、その世界「エルフ大陸」を展開している。公開から約6か月が経過し、ベータ版のまま運営されている。

CiDi Games が示した実績は次のとおりである（同社の発表による）。

項目数値
公開中のゲーム数約70本（月約10本を追加）
アカウント数35万超
1日あたりの利用者数約4万人
エルフ大陸の1日あたりの利用者数約3万人
150日目の定着率20〜30%
累計ゲームセッション数1,000万超
累計広告表示回数約2,500万回
エルフ大陸での累計滞在時間600万時間超
他者の土地への訪問回数400万回超
マーケットでの取引回数200万回超

CiDi Games の今後の方向性として、Piエルフの画像素材を外部の開発者に開放し、ブロックチェーン上で NFT（唯一性を証明できるデジタル資産）として対応づけること、NFT の発行所や売買所といった開発者向け道具の整備、独自トークンの Launchpad への上場が語られた。ただし、これらは同社の社内での方向性であり、独自トークンについては Pi Core Team との協議前であることが対話の中で明言された。確定した発表ではない。

また、CiDi Games は Pi Core Team との協力例として、KYCに関する質問が利用者から寄せられたことを報告し、KYC調査の質問票が2週間以内に整備・開始されたことを紹介した。iOS利用者の保存領域の問題への対応や、メインネット審査の迅速化、広告枠のチーム別集計といった改善も、開発者からの要望を受けて行われたと述べた。

ファンは今後の戦略として、外部の需要と Pi の共有資源（配布・注目・利用者獲得、利用者の同意を得た上での人の関与による作業やデータ、分散コンピューティング（多くのコンピュータに処理を分けさせること）、本人確認）を結びつける方針を説明した。ゲームは Pi と相性が良い分野であり、決済・交流・金融参加への入り口になると述べた。ステーブルコイン（価格が法定通貨などに連動して安定するよう設計されたコイン）の統合や追加の Web3（ブロックチェーンを基盤とする次世代のウェブの考え方）機能も、Pi通貨の中心的な役割を損なわない範囲で検討されている。
